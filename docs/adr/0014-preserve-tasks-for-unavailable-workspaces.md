# Preserve Tasks for unavailable Workspaces

When a Workspace Target is removed, loses authorization, or is temporarily unreachable, Agentic Layout will retain its Task Conversation and Task Artifacts rather than deleting or hiding the associated Durable Agent Tasks. The Project remains visible as a disabled History Menu group and its history remains readable, but its Tasks cannot receive a Prompt or perform a Workspace-aware Task Switch until access is restored; Workspace availability is presented separately from ACP Task Status.
