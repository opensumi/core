# Compose the Agent Task List inside the ACP Chat Slot

Agentic Layout will render its persistent Agent Task List as the left subregion of the existing ACP Chat Slot, with the Main Conversation Area beside it. The existing Agentic Workbench continues to own the editor and file tree, so this yields a four-region desktop workspace without changing IDE Layout lifecycle or shared workbench behavior.
