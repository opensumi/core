# Enhance the existing Agentic Layout

Agent-management improvements will extend OpenSumi's existing workspace-local Agentic Layout, where ACP Chat is the primary interaction surface. “Open in Agents” denotes activating that layout for the current Workspace Target; it does not create a separate cross-workspace Agent Task Center or register a session as a new task. This supersedes the root scope of ADR 0001; proposed artifacts that depend on a separate cross-workspace Task Center must be re-evaluated before implementation.
