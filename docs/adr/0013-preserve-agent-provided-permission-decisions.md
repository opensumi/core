# Preserve Agent-provided permission decisions

The Agent initiates a Permission Request and supplies its supported decision options, but cannot authorize itself. OpenSumi routes the request and may apply an existing user rule; otherwise Agentic Chat View presents the Agent-provided choices, including once or always variants when offered. The pending ACP request is rendered as an attention indicator and remains unresolved until a decision is available, including when no browser page is currently connected.
