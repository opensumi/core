# Combine platform Workspaces and Personal Projects

The Workspace Catalog will combine Platform Workspaces authorized by the Web IDE host with user personalization such as recent, pinned, and hidden state. Users may also create a directory in platform-authorized storage, give it a project name, and add it as a Personal Project. The project name is mutable display metadata: renaming it does not rename or move the backing directory. Personal Projects extend the user's catalog but do not grant access outside the host platform's storage and authorization boundaries.
